☕ Brew Haven — Coffee Landing Page

A modern, responsive coffee shop landing page built using HTML, CSS, and JavaScript.

---

🚀 Live Demo

👉 https://brew-haven-landing-page.vercel.app/

---

📌 Features

- Fully responsive design (mobile + desktop)
- Smooth scrolling navigation
- Interactive navbar with active states
- Coffee menu with pricing in ₹ (Indian Rupees)
- Gallery section
- Testimonials section
- Contact section with map
- Newsletter subscription UI
- Clean and minimal footer

---

🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
